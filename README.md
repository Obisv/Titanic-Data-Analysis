# Titanic Data Analysis

## Overview
This project analyses the Titanic dataset to identify the key factors that influenced passenger survival rates.

## Tools Used
- Microsoft Excel
- Power Query

## Key Findings
- Gender was the biggest factor — females survived at 72% vs 12% for males
- Passenger class was second biggest — first class at 61% vs third class at 24%
- Age group also played a role with children having the highest survival rate at 49%
- Embarkation location was an indirect factor driven by passenger class
